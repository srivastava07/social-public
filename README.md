# social-public

Public policy pages for the Meta application **kathaa.toons** (App ID `2252634102251757`),
served with GitHub Pages.

| page | URL |
| --- | --- |
| Privacy Policy | https://srivastava07.github.io/social-public/privacy/ |
| Terms of Service | https://srivastava07.github.io/social-public/terms/ |
| Data Deletion | https://srivastava07.github.io/social-public/data-deletion/ |

Meta requires a reachable Privacy Policy URL before an app can be switched from Development to
Live mode, and a Data Deletion URL for apps that use Facebook Login. Until the app is Live, content
it publishes is only visible to people with a role on the app — which is why these pages exist.

Static HTML only. Nothing here is generated from, or shares code with, the application itself.
