Data Deletion

Last updated 23 September 2026

How to remove everything the application holds. Meta requires this page for applications that use Facebook Login.

The only data this application holds is the operator's own access tokens, stored on the operator's own computer. There is no server to write to and no account to close.

Revoke the application's access

  • Facebook and Instagram — open Settings → Business integrations, find kathaa.toons, and choose Remove. Every token issued to it stops working immediately.
  • YouTube — open Google Account → Third-party access, select the application, and choose Remove access.

Delete the stored copy

Revoking access makes the stored tokens useless. To delete them outright, remove the application's local database file from the computer it runs on, or clear the saved credentials from within the application itself.

Content already published

Videos already published are ordinary posts on the Page, account or channel they were published to, and are owned by it. Delete them there, as you would any other post; this application keeps no copy beyond the operator's own machine.
